# Руководство пользователя SchoolBellTimer

Добро пожаловать в руководство пользователя программы **SchoolBellTimer** — офисных электронных часов с обратным отсчетом до конца уроков и перемен. Данное руководство поможет вам быстро настроить расписание звонков, настроить цветовую тему, установить фоновое изображение и организовать работу информационного табло на телевизоре или проекторе.

---

## 1. Главный экран и информационные блоки

Главное окно программы спроектировано для максимальной наглядности и читаемости с большого расстояния. Вся информация сгруппирована в центральной карточке, которая всегда находится строго по центру экрана:

```
+------------------------------------------------------------------------+
| [📋 Расписание уроков] [🎨 Тема часов] [🖼️ Фон окна] [⛶ F11] [👁️ Меню]  |
+------------------------------------------------------------------------+
|                                                                        |
|       +--------------------------------------------------------+       |
|       |              Вторник, 10 ноября 2026 г.                |       |
|       |                       10:14:32                         |       |
|       |                                                        |       |
|       |           [ ИДЕТ 2 УРОК (09:25 – 10:05) ]              |       |
|       |                                                        |       |
|       |                ДО ЗВОНКА ОСТАЛОСЬ                      |       |
|       |                       04:18                            |       |
|       |                                                        |       |
|       |       [========================.........]              |       |
|       |        Прошло 88% времени урока | Всего: 40 мин.       |       |
|       +--------------------------------------------------------+       |
|                                                                        |
+------------------------------------------------------------------------+
```

### Основные элементы карточки:
1. **Текущая дата и день недели:** Отображается на русском языке в полном формате.
2. **Системные часы (ЧЧ:ММ:СС):** Высококонтрастные моноширинные цифры текущего времени компьютера.
3. **Бейдж статуса урока/перемены:** Информационный блок с цветной рамкой:
   - `До начала занятий (первый урок в ЧЧ:ММ)` — до первого звонка утром.
   - `Идет N урок (ЧЧ:ММ – ЧЧ:ММ)` — во время урока.
   - `Перемена перед N уроком (до ЧЧ:ММ)` — во время перемены.
   - `Уроки окончены` — после завершения всех уроков на сегодня.
4. **Таймер обратного отсчета (ММ:СС):** Крупные электронные цифры, показывающие оставшееся время до окончания урока или перемены.
5. **Индикатор прогресса:** Горизонтальная шкала и текстовое пояснение, показывающие процент прошедшего времени текущего интервала.

## 2. Настройка расписания уроков и звонков

Чтобы открыть окно редактирования расписания:
1. Нажмите пункт меню **«📋 Расписание уроков»** в верхней панели или кликните правой кнопкой мыши по экрану и выберите **«📋 Настроить расписание...»**.
2. В появившемся окне отображается таблица всех уроков:

| Колонка | Описание | Пример значения |
|---|---|---|
| **№** | Порядковый номер (нумеруется автоматически) | `1`, `2`, `3` |
| **Название урока** | Название предмета или обозначение | `1 урок`, `Математика`, `Физика` |
| **Начало (ЧЧ:ММ)** | Время первого звонка на урок | `08:30` |
| **Окончание (ЧЧ:ММ)** | Время звонка с урока на перемену | `09:10` |

### Доступные действия в редакторе:
- **➕ Добавить урок:** Добавляет новую строку в таблицу. Программа автоматически рассчитывает ориентировочное время начала нового урока с учетом 10-минутной перемены.
- **❌ Удалить:** Удаляет выбранный в таблице урок.
- **▲ Вверх / ▼ Вниз:** Перемещает выделенную строку выше или ниже в списке.
- **🔄 По умолчанию:** Сбрасывает таблицу к стандартному демонстрационному расписанию (3 урока).
- **✔ Сохранить расписание:** Проверяет корректность введенных данных, сохраняет расписание в файл `settings.xml` и мгновенно обновляет отображение на главном экране без перезапуска программы.
- **Отмена:** Закрывает окно без сохранения изменений.

### Правила валидации:
- Время должно быть введено в 24-часовом формате `ЧЧ:ММ` (например, `08:30`, `9:25`, `14:00`).
- Время окончания каждого урока должно быть строго позже времени его начала.
- Уроки не должны пересекаться по времени: следующий урок не может начинаться раньше, чем закончился предыдущий.
- При сохранении программа автоматически упорядочивает уроки в хронологическом порядке.

## 3. Цветовые темы оформления

В программу встроены 2 офисные темы, разработанные с учетом рекомендаций по контрастности и эргономике:

### Тема 1: «🌙 Офисная темная (Бирюза / Неон)»
- **Рекомендуется:** Для проекторов, темных аудиторий, вечернего времени или снижения нагрузки на зрение.
- **Цвета:** Глубокий темно-графитовый фон, неоновые бирюзовые индикаторы статуса и яркие мятно-зеленые цифры обратного отсчета.

### Тема 2: «☀️ Офисная светлая (ЖК / Синий)»
- **Рекомендуется:** Для хорошо освещенных школьных холлов, ярких настенных панелей и светлых интерьеров.
- **Цвета:** Светло-серый фон окна, белоснежная карточка, темно-графитовое системное время и классические темно-синие цифры в стиле строгих офисных жидкокристаллических дисплеев.

**Как переключить тему:**
- Через верхнее меню: **«🎨 Тема часов»** -> выберите тему.
- Через контекстное меню: кликните правой кнопкой мыши -> **«🎨 Переключить тему»**.

## 4. Настройка фона окна (цвет или изображение)

Вы можете изменить внешний вид главного экрана, настроив пользовательский цвет или фоновое изображение (например, фирменный паттерн учебного заведения, логотип школы или фото здания):

1. **Установка однотонного цвета:**
   - Откройте меню **«🖼️ Фон окна»** -> **«🎨 Выбрать цвет фона...»**.
   - В открывшейся системной палитре `ColorDialog` укажите нужный оттенок и нажмите **OK**.
2. **Установка картинки (обоев):**
   - Откройте меню **«🖼️ Фон окна»** -> **«📁 Выбрать фоновое изображение...»**.
   - Выберите графический файл (`.jpg`, `.jpeg`, `.png`, `.bmp`) на компьютере.
   - Изображение будет аккуратно растянуто на весь экран под карточкой часов.
3. **Сброс к фону по умолчанию:**
   - Откройте меню **«🖼️ Фон окна»** -> **«🔄 Сбросить фон (по умолчанию)»**.

## 5. Режим информационного табло (ТВ / Проектор)

Для вывода часов на отдельный монитор, настенный телевизор или школьный проектор предусмотрены специальные функции:

### Полноэкранный режим (Fullscreen)
- Нажмите клавишу **`F11`** на клавиатуре (или выберите пункт **«⛶ Полный экран (F11)»** в меню).
- Окно развернется на весь экран без рамок, заголовка и границ Windows.
- Для возврата в оконный режим повторно нажмите **`F11`** или клавишу **`Esc`**.

### Скрытие панели инструментов
- Чтобы убрать верхнюю строку меню и оставить на экране только часы, нажмите пункт меню **«👁️ Скрыть меню»**.
- Меню исчезнет, а карточка часов плавно займет центр освободившегося пространства.

### Как вернуть меню, если оно скрыто?
- Нажмите клавишу **`Esc`** на клавиатуре.
- Нажмите сочетание клавиш **`Alt + M`**.
- Кликните **правой кнопкой мыши** в любом месте окна и выберите **«👁️ Показать / скрыть верхнее меню»**.

## 6. Быстрое тиражирование на другие компьютеры (`settings.xml`)

Все настройки и расписание хранятся в одном компактном файле `settings.xml` рядом с `SchoolBellTimer.exe`.

Чтобы быстро перенести настроенное расписание на другие компьютеры или флешки:
1. Настройте расписание на одном основном компьютере.
2. Скопируйте файл `settings.xml` на другие ПК в ту же папку, где лежит `SchoolBellTimer.exe`.
3. При запуске программа сразу подхватит готовые данные.

### Пример файла `settings.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<AppSettings xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns:xsd="http://www.w3.org/2001/XMLSchema">
  <Theme>DarkOffice</Theme>
  <BgMode>DefaultTheme</BgMode>
  <CustomBgColorArgb>-15460836</CustomBgColorArgb>
  <BackgroundImagePath />
  <BackgroundImageLayout>Stretch</BackgroundImageLayout>
  <IsFullScreen>false</IsFullScreen>
  <HideToolBar>false</HideToolBar>
  <Lessons>
    <LessonItem>
      <Number>1</Number>
      <Name>1 урок</Name>
      <StartTime>08:30</StartTime>
      <EndTime>09:10</EndTime>
    </LessonItem>
    <LessonItem>
      <Number>2</Number>
      <Name>2 урок</Name>
      <StartTime>09:25</StartTime>
      <EndTime>10:05</EndTime>
    </LessonItem>
    <LessonItem>
      <Number>3</Number>
      <Name>3 урок</Name>
      <StartTime>10:15</StartTime>
      <EndTime>10:55</EndTime>
    </LessonItem>
    <LessonItem>
      <Number>4</Number>
      <Name>4 урок</Name>
      <StartTime>11:15</StartTime>
      <EndTime>11:55</EndTime>
    </LessonItem>
    <LessonItem>
      <Number>5</Number>
      <Name>5 урок</Name>
      <StartTime>12:15</StartTime>
      <EndTime>12:55</EndTime>
    </LessonItem>
  </Lessons>
</AppSettings>
```

Вы также можете напрямую редактировать этот файл в «Блокноте» при закрытой программе.
