# Архитектура и техническая документация SchoolBellTimer

## 1. Обзор архитектуры

Программа **SchoolBellTimer** спроектирована по принципам максимальной надежности, автономности и минимального потребления системных ресурсов:
- **Целевая платформа:** Microsoft .NET Framework 3.5.
- **Совместимость с компилятором:** C# 3.0 (без синтаксиса C# 4.0+, `async/await`, интерполяции строк `$""` и `nameof`).
- **Сторонние зависимости:** 0 внешних DLL (только стандартные сборки платформы Windows).
- **Размер памяти:** 15–25 МБ RAM во время работы.
- **Нагрузка на CPU:** < 0.1% благодаря эффективному таймеру 500 мс и адресной перерисовке.

```
+-------------------------------------------------------------------------+
|                                Program                                  |
|         - Точка входа STAThread                                         |
|         - Глобальный перехват Application.ThreadException               |
+------------------------------------+------------------------------------+
                                     |
                                     v
+------------------------------------+------------------------------------+
|                               MainForm                                  |
|  - Главный цикл отображения (System.Windows.Forms.Timer 500 мс)         |
|  - Центрирование карточки (CenterClockCard)                             |
|  - Управление темами и фоновым рисунком                                 |
|  - Отрисовка без мерцания (DoubleBufferedPanel)                         |
+-------------------+--------------------------------+--------------------+
                    |                                |
                    v                                v
+-------------------+--------------+   +-------------+--------------------+
|          ScheduleForm            |   |           AppSettings            |
|  - DataGridView редактор уроков  |   |  - Модели LessonItem             |
|  - Валидация формата ЧЧ:ММ       |   |  - Палитры ThemePalette          |
|  - Проверка пересечений          |   |  - XmlSerializer (settings.xml)  |
|  - Хронологическая сортировка    |   |  - Демо-конфигурация             |
+----------------------------------+   +----------------------------------+
```

## 2. Компоненты и классы системы

### 2.1. `Program.cs` (Управление жизненным циклом)
Отвечает за инициализацию подсистемы Windows Forms (`Application.EnableVisualStyles()`, `Application.SetCompatibleTextRenderingDefault(false)`) и установку глобальных перехватчиков необработанных исключений (`Application.ThreadException` и `AppDomain.CurrentDomain.UnhandledException`). Это предотвращает аварийное падение программы в случае непредвиденных системных сбоев.

### 2.2. `AppSettings.cs` (Модель данных и хранилище настроек)
- **`LessonItem`:** Класс представления одного урока. Хранит номер, название, строковое время начала и окончания. Содержит вспомогательный метод `TryParseTimeString` для безопасного разбора времени вида `"ЧЧ:ММ"`.
- **`ThemePalette`:** Описывает полную цветовую схему (цвета фона, карточки, рамки, системных часов, обратного отсчета, бейджа статуса и панелей). Предоставляет статические фабричные методы `GetDarkOfficePalette()` и `GetLightOfficePalette()`.
- **`AppSettings`:** Корневой контейнер конфигурации, сериализуемый в XML. Реализует методы `Load(filePath)` и `Save(settings, filePath)`. При отсутствии файла на диске автоматически создает демонстрационное расписание (3 урока) и сохраняет его рядом с `.exe`.

### 2.3. `MainForm.cs` (Главное окно и графический движок)
- Объединяет разметку элементов без использования внешних файлов `.Designer.cs` (все контролы инициализируются программно, что упрощает прямую компиляцию через `csc.exe`).
- Реализует подписку на таймер с интервалом 500 мс. Интервал в 500 мс выбран намеренно: он гарантирует, что смена системной секунды будет отображена с задержкой не более полусекунды, исключая пропуски секунд без избыточной нагрузки на процессор.
- Поддерживает переключение полноэкранного режима (`F11`), скрытие панели управления, вызов контекстного меню по правому клику мыши и смену фона.

### 2.4. `ScheduleForm.cs` (Редактор расписания)
- Предоставляет пользователю интуитивный табличный интерфейс (`DataGridView`) для манипуляции списком уроков.
- Включает операции добавления, удаления, перемещения строк («Вверх» / «Вниз») и сброса к заводским настройкам.
- Выполняет строгую проверку пользовательского ввода: корректность формата времени, условие `Время окончания > Время начала` и проверку на отсутствие временных пересечений между соседними уроками.

### 2.5. `DoubleBufferedPanel` и `LessonRowControl` (Компоненты плавной отрисовки и строки расписания)
- **`DoubleBufferedPanel`:** Наследник стандартного `System.Windows.Forms.Panel`, у которого в конструкторе принудительно активированы стили `AllPaintingInWmPaint`, `UserPaint`, `OptimizedDoubleBuffer` и `ResizeRedraw`. Это полностью исключает мерцание (flicker) при перерисовке фона, карточек и прогресс-бара.
- **`LessonRowControl`:** Специализированный виджет строки урока с собственной перерисовкой (`OnPaint`). В зависимости от состояния перечисления `LessonRowState` (`Upcoming`, `Active`, `NextBreak`, `Past`), он плавно отрисовывает номерной бейдж, название урока, время интервала, левую акцентную полосу и правый индикаторный маркер (`● ИДЕТ`, `СЛЕДУЮЩИЙ`, `✓`).
- **`LessonRowState`:** Перечисление состояний строки урока, управляемое конечным автоматом метода `UpdateScheduleListHighlight`.

### 2.6. Механизм принудительного удержания окна поверх всех (Always on Top Engine)
- Использует нативную функцию Win32 API `SetWindowPos` из библиотеки `user32.dll` с флагами `HWND_TOPMOST (-1)` и `SWP_NOMOVE | SWP_NOSIZE | SWP_NOACTIVATE | SWP_SHOWWINDOW`.
- **Защита от перехвата Z-Order:** Удержание окна на вершине экрана подкрепляется тройным контуром:
  1. Первичное включение при запуске приложения (`TopMost = true`).
  2. Перехват события `MainForm.Deactivate` — при попытке сторонней программы занять фокус часы мгновенно возвращаются на вершину.
  3. Циклический контроль в таймере 500 мс через `EnsureTopMost()`.
- **Корректная работа с модальными окнами:** При открытии редактора расписания (`ScheduleForm`) или системных диалогов выставляется флаг `isModalDialogOpen = true`, исключающий блокировку дочерних окон ввода.

## 3. Математическая модель и алгоритм определения состояния

В каждый момент времени $t$ (где $t = \text{DateTime.Now.TimeOfDay}$) расписание уроков $L = \{l_1, l_2, \dots, l_n\}$, отсортированное по времени начала ($s_1 < s_2 < \dots < s_n$), однозначно разбивает сутки на непересекающиеся временные интервалы:

```
[00:00] ---- До начала уроков ----> [s_1]
[s_1]   ==== Урок 1 ============== [e_1]
[e_1]   ---- Перемена перед 2 ----> [s_2]
[s_2]   ==== Урок 2 ============== [e_2]
...
[s_n]   ==== Урок n ============== [e_n]
[e_n]   ---- Уроки окончены ------> [23:59:59]
```

### Алгоритм вычисления (метод `UpdateClockAndSchedule`):

1. **Если $L = \emptyset$ (расписание пусто):**
   $$\text{Статус} = \text{"Расписание уроков не задано"}, \quad \text{Таймер} = \text{"00:00"}$$

2. **Если $t < s_1$ (время до первого урока дня):**
   - $\text{Целевое время} = s_1$
   - $\text{Остаток времени} \Delta t = s_1 - t$
   - $\text{Статус} = \text{"До начала занятий (первый урок в } s_1 \text{)"}$
   - $\text{Прогресс} = 0\%$

3. **Если $\exists i \in [1, n] : s_i \le t < e_i$ (текущее время внутри урока $l_i$):**
   - $\text{Целевое время} = e_i$
   - $\text{Остаток времени} \Delta t = e_i - t$
   - $\text{Статус} = \text{"Идет " } + l_i.\text{Name} + \text{" (" } + s_i + \text{" – " } + e_i + \text{")"}$
   - $\text{Процент выполнения} P = \left( \frac{t - s_i}{e_i - s_i} \right) \times 100\%$

4. **Если $\exists i \in [1, n-1] : e_i \le t < s_{i+1}$ (текущее время внутри перемены между $l_i$ и $l_{i+1}$):**
   - $\text{Целевое время} = s_{i+1}$
   - $\text{Остаток времени} \Delta t = s_{i+1} - t$
   - $\text{Статус} = \text{"Перемена перед " } + l_{i+1}.\text{Name} + \text{" (до " } + s_{i+1} + \text{")"}$
   - $\text{Процент выполнения} P = \left( \frac{t - e_i}{s_{i+1} - e_i} \right) \times 100\%$

5. **Если $t \ge e_n$ (все уроки дня завершились):**
   - $\text{Статус} = \text{"Уроки окончены"}$
   - $\text{Таймер} = \text{"00:00"}$
   - $\text{Прогресс} = 100\%$

### Форматирование времени таймера:
Если оставшееся время $\Delta t < 60 \text{ мин}$, оно отображается строго в формате `ММ:СС`:
$$\text{string.Format}("{0:D2}:{1:D2}", \Delta t.\text{Minutes}, \Delta t.\text{Seconds})$$
Если остаток превышает 1 час (например, утром до начала занятий), формат плавно расширяется до `ЧЧ:ММ:СС`.

## 4. Алгоритм центрирования и адаптивной двухколоночной верстки

Программа автоматически адаптирует макет в зависимости от ширины окна, разрешения экрана и пользовательского флага `ShowScheduleList`:

1. **Режим только часов (если `ShowScheduleList == false` или `Width < 780px`):**
   - Карточка часов занимает центр рабочей области окна.
   - Габариты: $W_{\text{card}} = \min(W_{\text{avail}} - 40, 780)$, $H_{\text{card}} = \min(H_{\text{avail}} - 40, 480)$.
   - Координаты: $X = \frac{W_{\text{avail}} - W_{\text{card}}}{2}$, $Y = H_{\text{menu}} + \frac{H_{\text{avail}} - H_{\text{card}}}{2}$.

2. **Двухколоночный режим (Часы + Боковое расписание):**
   - Активируется на стандартных и широкоформатных экранах ($\ge 780 \text{ px}$, включая мониторы 16:9, телевизоры и проекторы 1080p/4K).
   - Общая ширина группы карточек: $W_{\text{group}} = \min(W_{\text{avail}} - 40, 1180 \text{ px})$.
   - Ширина правой карточки расписания рассчитывается как $W_{\text{sched}} \approx 35\% \times W_{\text{group}}$ (с ограничением в диапазоне от 300 до 380 px).
   - Ширина левой карточки часов: $W_{\text{clock}} = W_{\text{group}} - W_{\text{sched}} - \text{gap}$.
   - Координаты левого угла группы: $X_{\text{start}} = \frac{W_{\text{avail}} - W_{\text{group}}}{2}$, $Y_{\text{start}} = H_{\text{menu}} + \frac{H_{\text{avail}} - H_{\text{common}}}{2}$.
   - Карточка часов размещается в $X_{\text{start}}$, а карточка расписания — в $X_{\text{start}} + W_{\text{clock}} + \text{gap}$.
   - Внутренние элементы карточки часов и строки уроков динамически масштабируются по ширине своих родительских панелей.

## 5. Графика, типографика и устранение визуального дрожания

- **Шрифты:**
  - Для индикации времени и секунд используется моноширинный шрифт **Consolas** (с автоматическим системным резервом). Моноширинность критически важна: цифры `1` и `8` имеют одинаковую ширину глифа, благодаря чему текст таймера не смещается и не «дрожит» по горизонтали при смене секунд.
  - Для текстовых подписей, статусов и даты используется семейство **Segoe UI**, обеспечивающее превосходную четкость при ClearType сглаживании.
- **Отрисовка фона без блокировки файлов:**
  - Загрузка пользовательских картинок осуществляется через чтение байтов в `MemoryStream` (`Image.FromStream(ms)`), что оставляет исходный файл картинки свободным для перезаписи или удаления пользователем в проводнике Windows.

## 6. Формат сериализации данных

Конфигурация сериализуется стандартным классом `System.Xml.Serialization.XmlSerializer`.
- Кодировка: **UTF-8**.
- Корневой узел: `<AppSettings>`.
- Свойства уроков сохраняются в виде упорядоченного списка `<Lessons><LessonItem>...`.
- Отказоустойчивость: в случае повреждения файла настроек (например, при внезапном отключении питания ПК) метод `AppSettings.Load` перехватывает исключение и мгновенно возвращает корректную демонстрационную конфигурацию по умолчанию, предотвращая сбой старта приложения.
