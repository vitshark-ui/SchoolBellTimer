# SchoolBellTimer (Электронные офисные часы и расписание звонков)

**SchoolBellTimer** — это ультралегкое, надежное и автономное десктопное приложение на C# Windows Forms в строгом офисном стиле для школ, гимназий, лицеев, колледжей и учебных центров. Программа предназначена для отображения текущего системного времени, статуса текущего урока или перемены, а также крупного таймера обратного отсчета до школьного звонка. Идеально подходит для вывода на настенные телевизоры, информационные панели в холлах и проекторы в классах.

---

## Ключевые особенности и преимущества

- **0 байт на скачивание рантайма:** Разработано под целевую платформу **.NET Framework 3.5**, которая по умолчанию предустановлена во все версии Windows 7, Windows 8, Windows 10 и Windows 11.
- **0 сторонних зависимостей:** Никаких внешних библиотек или NuGet-пакетов. Используются исключительно базовые сборки Windows (`System`, `System.Drawing`, `System.Windows.Forms`, `System.Xml`).
- **Идеальная центровка и читаемость издалека:** Крупные моноширинные цифровые шрифты, контрастные стильные бейджи и автоматическое центрирование карточки часов при любых разрешениях экрана (от нетбуков до 4K-панелей).
- **Плавная смена секунд без мерцания:** Полноценная аппаратная двойная буферизация (`DoubleBuffered = true` и `OptimizedDoubleBuffer`) устраняет любое дрожание интерфейса при ежесекундном обновлении.
- **Встроенный редактор расписания:** Удобное диалоговое окно для добавления, изменения, сортировки и удаления уроков с автоматической проверкой корректности времени.
- **2 встроенные дизайнерские темы:**
  - *Офисная темная:* Темно-графитовый фон, неоновые бирюзовые и мятно-зеленые электронные индикаторы.
  - *Офисная светлая:* Стильный светло-серый фон, строгие темно-синие и графитовые ЖК-индикаторы.
- **Кастомизация фона:** Возможность установить однотонный цвет через цветовую палитру или выбрать любое изображение (`.jpg`, `.png`, `.bmp`) в качестве фонового рисунка.
- **Режим информационного табло:** Полноэкранный режим (`F11`) и скрытие панели управления позволяют оставить на экране монитора или телевизора только чистые часы.

## Инструкция по сборке

Приложение можно собрать как в современной среде разработки (Visual Studio), так и **в 1 клик на «чистой» Windows 7 без установки каких-либо IDE и SDK**.

### Вариант 1. Сборка встроенным компилятором Windows 7 (без установки IDE)

В операционной системе Windows 7 (и выше) уже присутствует встроенный компилятор `csc.exe`.

1. Откройте командную строку (`cmd.exe`) или PowerShell в папке с исходными файлами проекта.
2. Выполните команду компиляции:

```cmd
C:\Windows\Microsoft.NET\Framework\v3.5\csc.exe /target:winexe /out:SchoolBellTimer.exe /warn:4 Program.cs AppSettings.cs MainForm.cs ScheduleForm.cs /reference:System.dll,System.Drawing.dll,System.Windows.Forms.dll,System.Xml.dll,System.Core.dll
```

3. В этой же папке мгновенно появится готовый автономный исполняемый файл `SchoolBellTimer.exe`.

> **Совет для быстрой сборки:** Вы можете создать в папке проекта текстовый файл `build.bat` со следующим содержимым:
> ```bat
> @echo off
> echo Сборка SchoolBellTimer под .NET Framework 3.5...
> C:\Windows\Microsoft.NET\Framework\v3.5\csc.exe /target:winexe /out:SchoolBellTimer.exe Program.cs AppSettings.cs MainForm.cs ScheduleForm.cs /reference:System.dll,System.Drawing.dll,System.Windows.Forms.dll,System.Xml.dll,System.Core.dll
> if %ERRORLEVEL% EQU 0 (
>     echo [УСПЕХ] Файл SchoolBellTimer.exe успешно создан!
> ) else (
>     echo [ОШИБКА] При сборке возникли ошибки.
> )
> pause
> ```

### Вариант 2. Сборка через Visual Studio

1. Откройте файл проекта `SchoolBellTimer.csproj` в любой версии Visual Studio (2008, 2010, 2012, 2015, 2017, 2019, 2022).
2. Выберите конфигурацию **Release** и платформу **Any CPU**.
3. Нажмите `Ctrl + Shift + B` (или меню *Сборка -> Собрать решение*).
4. Готовый файл будет находиться в директории `bin\Release\SchoolBellTimer.exe`.

## Первый запуск и начальное расписание

При первом запуске исполняемого файла программа проверяет наличие файла конфигурации `settings.xml` рядом с `.exe`. Если файл отсутствует, он создается автоматически со следующим демонстрационным расписанием:

- **1 урок:** 08:30 – 09:10
- **2 урок:** 09:25 – 10:05
- **3 урок:** 10:15 – 10:55

Все изменения расписания, выбранная тема оформления и настройки заднего фона сохраняются в локальный XML-файл и восстанавливаются при последующих запусках.
